Antes de cada consumo, la API de Mobiconnect responde una pregunta: **¿este tenant puede usar este producto, en este scope y con esta cantidad?** Cada unidad autorizada queda medida y valorizada en un registro auditable.

:::note[Estás en staging]
Autenticación OAuth2, tenants sintéticos y sin dinero real. Las URLs de esta documentación son de ejemplo hasta la apertura pública del portal.
:::

## Tres reglas que no cambian

- **Deny-by-default.** Toda ruta exige un scope explícito. Lo que no sea `200` con `allow: true` es deny.
- **La cuota agotada no es un error.** Responde `200 {"allow": false, "reason": "quota_exceeded"}`. El `429` es del gateway, no del contrato.
- **Fail-closed.** Si el PDP no puede decidir, responde `503 {"allow": false, "error": "pdp_unavailable"}`. Nunca se sirve a ciegas.
